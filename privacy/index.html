隐私政策

更新日期：2026-10-21 · 适用于 Tessecos / 归序 1.0.0

无需创建游戏账号。核心玩法离线运行。

游戏没有广告、分析或追踪 SDK，不向开发者上传游戏存档。

Apple 负责处理 App Store 购买。启用 iCloud 同步的版本可保存私有云端存档；本机保留缓存。

1. 开发团队与适用范围

本政策说明由 Tessecos Studio 独立开发团队提供和维护的 Tessecos / 归序游戏及本支持网站如何处理数据。有关隐私的问题，请使用本页末尾的支持邮箱联系。

2. 游戏数据保存在设备中

当前关卡、棋盘与操作历史、计时、生成地图、通关成绩、积分与游戏币余额、道具库存、主题与购买权益、已处理交易编号，以及语言、声音和外观偏好保存在应用的本地目录，用于恢复游戏、展示记录和避免重复发放。

游戏不要求另建游戏账号，也没有开发者自建的存档服务器。启用同步的 iOS 版本通过 Apple CloudKit，将存档和交易去重记录保存在用户的 iCloud 私有数据库中，开发团队无法读取私有存档。iCloud 是否可用取决于系统账号、网络及存储空间。

3. Apple 内购服务

游戏使用 Apple StoreKit 2 查询商品、核验购买、处理游戏币发放及恢复全部皮肤包权益。Apple 处理账号、支付确认与交易，游戏不会读取 Apple 账号密码或银行卡信息。应用接收商品信息、核验结果及交易编号，并保存必要的处理记录。购买时使用不含邮箱的标识关联 iCloud 存档与苹果订单，防止跨账号重复领取。

Apple 服务的数据处理适用 Apple 隐私政策。全部皮肤包为非消耗型商品，游戏币为消耗型商品；恢复购买用于核验皮肤包，不能重建已完成充值交易对应的本地游戏币余额。

4. 权限、广告与追踪

本版本不接入广告、分析或追踪 SDK，不请求相机、麦克风、定位或通讯录权限。

5. 保存、恢复与设备更换

以下云同步说明适用于启用 iCloud 功能的 iOS 版本。在 iPhone 和 iPad 上登录同一 iCloud 账号并联网，可同步游戏币、积分、道具、已购主题和通关记录，并在重新安装后恢复已同步的数据。本机缓存随游戏操作更新。未同步成功的数据无法从云端恢复；更换设备前请先在设置中确认同步状态。

共享钱包的充值、兑换、购买及道具使用需要联网确认，避免多台设备重复使用同一笔余额。断网仍可游玩，通关奖励会等待同步。进行中的棋盘按设备保留，后台同步不会替换正在游玩的对局。

删除应用及其本机数据不会主动删除已保存的 iCloud 存档；云端数据可在系统 iCloud 设置中管理。若同时删除云端与本机记录，就无法从该存档恢复。苹果皮肤包权益仍可使用原购买账号通过“恢复购买”核验；已消费的游戏币不会重新发放。

6. 支持邮件

如果你主动发送支持邮件，运营者会收到你的邮箱地址、邮件内容及你主动附上的截图或设备信息，仅用于回复和处理请求。请勿发送密码、完整付款凭证或其他不必要的敏感信息。支持邮件仅在处理问题及适用要求所需的期间保留；你可以通过支持邮箱提出访问或删除请求。

7. 本网站与外部链接

本网站是静态页面，没有广告、分析脚本、登录系统或在线表单。网站由 GitHub Pages 托管；GitHub 会为安全目的记录访问者 IP 等技术信息，具体请参阅 GitHub Pages 数据说明和 GitHub 隐私声明。

访问 Apple、GitHub 等外部网站时，相应网站和浏览器会按各自政策处理访问数据。

8. 政策更新

若应用的数据处理方式发生变化，将更新本政策及必要的商店隐私说明，并标明更新日期。

Privacy policy

Updated: 2026-10-21 · Applies to Tessecos / 归序 1.0.0

No game account is required. Core gameplay works offline.

No advertising, analytics or tracking SDKs. Game saves are not uploaded to the developer.

Apple handles App Store purchases. Versions with iCloud sync can keep private cloud saves alongside a local cache.

1. Developer team and scope

This policy describes how the independent development team Tessecos Studio handles data for the Tessecos / 归序 game and this support website. Contact the support email below for privacy questions.

2. Data stored on your device

The current level, board and action history, elapsed time, generated maps, scores, points and coin balances, tool inventory, themes and purchase entitlements, processed transaction IDs, and language, audio and appearance preferences are stored in the app’s local directory. They support game recovery, personal records and duplicate-reward prevention.

No separate game account or developer-operated save server is required. With sync enabled in supported iOS versions, Apple CloudKit stores saves and transaction deduplication records in your private iCloud database. The development team cannot read private saves. Availability depends on your system account, network and storage space.

3. Apple purchases

The game uses Apple StoreKit 2 to query products, verify purchases, credit coins and restore the All Skins Pack entitlement. Apple handles account, payment confirmation and transaction processing. The game does not read your Apple Account password or payment-card details. It receives product information, verification results and transaction IDs, keeping necessary processing records. A purchase identifier without an email address links the iCloud save to Apple orders to prevent duplicate delivery across accounts.

Apple services are governed by the Apple Privacy Policy. The All Skins Pack is non-consumable; coin packs are consumable. Restore Purchases checks the skin-pack entitlement and cannot rebuild the local coin balance from completed coin transactions.

4. Permissions, advertising and tracking

This version has no advertising, analytics or tracking SDKs and does not request camera, microphone, location or contacts permissions.

5. Retention, recovery and device changes

These cloud features apply to iOS versions with iCloud sync enabled. Sign in to the same iCloud account on iPhone and iPad and connect to sync coins, points, tools, purchased themes and completion records. Reinstalling can restore data that has already synced. Local caches update as you play. Unsynced data cannot be recovered from the cloud; check sync status in Settings before changing devices.

Shared-wallet top-ups, exchanges, purchases and tool use require online confirmation to avoid spending the same balance on multiple devices. Offline play remains available; rewards wait to sync. Each device retains its board snapshot, and background sync never replaces an active game.

Deleting the app and its local data does not itself delete saved iCloud records. Manage cloud data in system iCloud settings. Deleting both cloud and local records prevents recovery from that save. Restore Purchases can still verify the skin-pack entitlement with the original purchasing Apple Account. Spent coins are not granted again.

6. Support email

If you email support, the operator receives your email address, message and any screenshots or device information you choose to include, solely to respond and handle your request. Do not send passwords, full payment records or unnecessary sensitive information. Support messages are kept only as needed to resolve requests and meet applicable requirements. Contact support to request access or deletion.

7. This website and external links

This is a static website with no ads, analytics scripts, sign-in system or web forms. GitHub Pages hosts the site. GitHub logs visitors’ IP addresses and technical information for security; see GitHub Pages data collection and the GitHub Privacy Statement.

When you visit external Apple or GitHub pages, those websites and your browser process visits under their own policies.

8. Changes

If data handling changes, this policy and necessary App Store privacy disclosures will be updated, with a revised date.
